# 公开仓库整理记录

本页保留首次发布整理的历史检查。2026-09-24 版本的五种宏观配置及 140 项宏观、37 项微观测试见 [配置说明](macro-configurations.md) 和 [当前发布检查](release-validation.json)；不将本页的旧测试数量作为当前数量。

本次将原研究工作区整理为 `sc2musa/Jev_Star`，目录为 `macro/`、`micro/`、`scripts/`、`docs/`、`paper/` 和 `licenses/`。

## 保留

- 宏观当前 `macro-v2.2.1`：JEV/Astra 调用、Protoss 基类、动作契约、候选筛选、执行反馈、导航、日志、离线报告和 replay 工具；102 项原有回归测试及六张梯图。
- 微观当前 P0：完整 JEV 闭环、每图 Astra 计划、固定步进与单独的 realtime 探测入口、回放工具、SMAC-Hard 所需底层、修改版 PySC2、37 项原有测试。
- 35 张注册 SMAC 地图，按原文件字节集中到 `micro/SMAC_HARD_maps/`，没有遗漏旧版本目录中的有效地图。
- 一份最新论文 PDF、编译所需 LaTeX/图表/日志引用，以及论文使用的固定统计数据。
- 各组件来源、原文件哈希和保留的上游许可证。

原研究工作区和原始实验档案没有删除，也没有修改冻结基线。这里记录的是公开发布树的清理，不是重新进行战术优化或抹去失败实验。

## 必要的代码整理

宏观包初始化不再注册旧 Gym 环境；`Protoss_bot.py` 移除四个旧进程启动/命名辅助函数及它们引入的无关配置，保留 `Protoss_Bot` 类。SMAC 地图目录统一后，地图查找器不再回退到旧训练树。统一入口负责选择独立环境和工作目录，模型动作逻辑继续由各模块承担。

整理后的源文件与原文件的对应关系、哈希和差异说明见 [source-manifest.json](source-manifest.json)。论文派生快照中的工作区绝对路径转换为对应模块的相对路径；原始日志未修改。

## 验证

在新建的两个 Python 3.10 虚拟环境中重新安装精简依赖，并运行宏观 102 项、微观 37 项离线测试。验证覆盖导入、动作/计划接口、错误处理、日志及固定步进的现有回归。启动帮助、地图资产哈希、依赖一致性、文件链接和发布内容另行核对。

此整理没有启动新对局或调用付费模型。回归通过不表示在本次发布目录中重新取得了历史胜绩。宏观旧事件循环测试仍会出现已有的 ResourceWarning，测试结果通过；没有为整理任务改变其运行语义。
